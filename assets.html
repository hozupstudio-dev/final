에셋 관리

로고·영상·유튜브 비하인드·트랙 오디오를 한 곳에서 교체합니다. 값을 바꾼 뒤 아래 media.js 생성으로 코드를 만들어 assets/js/media.js 에 덮어쓰면 모든 페이지에 적용됩니다.

적용 방법
① 로고/영상 — 같은 이름으로 assets/media/ 에 덮어쓰거나, 칸에 경로/URL 입력
② 비하인드 — 유튜브 영상 ID 입력(임베드 재생, 제목 자동)
③ 트랙 오디오 — 기본은 데모 합성음. 실제 음원은 seed 번호 + URL로 추가
※ 파일 선택은 미리보기 전용입니다. 영구 적용은 경로/URL 또는 같은 이름 파일 교체로 하세요.
