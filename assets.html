에셋 관리

모든 로고·영상·오디오를 한 곳에서 교체합니다. 칸에 URL을 붙여넣거나 파일 선택으로 미리보기 한 뒤, 아래 media.js 생성으로 코드를 만들어 assets/js/media.js 에 덮어쓰면 모든 페이지에 바로 적용됩니다.

적용 방법 2가지
① 가장 쉬움 — 실제 파일을 기존과 같은 이름으로 assets/media/ 에 덮어쓰기 (코드 변경 0)
② 경로/URL 교체 — 아래 칸에 경로나 외부 URL 입력 → media.js 생성 → assets/js/media.js 에 붙여넣기
※ 파일 선택은 이 페이지에서 미리보기 전용입니다(브라우저 보안상 임시 주소). 실제 적용은 ①의 경로나 ②의 URL로 하세요.
