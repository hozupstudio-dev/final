# XDINARY HEROES — 인터랙티브 팬사이트 (과제 제출본)

엑스디너리히어로즈(Xdinary Heroes)의 아이덴티티를 다감각적으로 경험할 수 있도록 기획한 인터랙티브 웹페이지입니다.
기획안의 세 가지 콘셉트(DISCOGRAPHY · ARCHIVE · Behind The Scene)를 각각 한 페이지로 구현하였습니다.

## 📌 미디어(영상·음원) 처리 방식 — 꼭 읽어 주세요

본 과제의 영상·음원은 **저작권 보호 자료**로, 파일(mp4·mp3) 형태로 합법적으로 **다운로드하여 포함할 수 없습니다.**
따라서 해당 미디어는 **공식 유튜브 영상을 링크(임베드) 방식으로 연결**하여 웹페이지 안에서 바로 재생되도록 구현하였습니다.

- **DISCOGRAPHY**: 앨범별 배경 영상을 유튜브로 연결
- **ARCHIVE**: 곡 제목을 누르면 유튜브 음원이 (영상 없이) **소리로** 재생
- **Behind The Scene**: 비하인드 영상을 유튜브로 연결

### ⚠️ 유튜브 광고에 관하여
위와 같이 유튜브 임베드 방식을 사용했기 때문에, 영상·음원 재생 시작 시 **유튜브 측 광고가 표시될 수 있습니다.**
이는 유튜브 플레이어의 정책에 따른 것으로 **제작자가 제어할 수 없는 부분**이며, 광고가 끝나면 정상적으로 본편이 재생됩니다.
(만약 음원을 직접 파일로 보유하고 있다면 광고 없이 재생되도록 교체할 수 있도록 구성해 두었습니다 — 아래 *에셋 교체* 참고.)

### 이미지 / 로고에 관하여
앨범 커버·로고 역시 저작권을 고려하여 실제 이미지를 포함하지 않았으며, **콘셉트 확인용 플레이스홀더(엠블럼)** 로 제작하였습니다.
디스코그래피·트랙 리스트 등 **텍스트 정보**는 공개 자료(위키피디아 등)를 참고하여 작성하였습니다.

## 실행 방법

> ⚠️ 유튜브 재생을 위해 **http(s)** 로 접속해야 합니다. (파일을 더블클릭하는 `file://` 방식은 유튜브가 차단됩니다.)

- **온라인**: GitHub Pages 주소로 접속 → `…/discography.html`, `…/archive.html`, `…/behind.html`
- **로컬**: 프로젝트 폴더에서 `python3 -m http.server 8000` 실행 후 `http://localhost:8000/discography.html` 접속

## 페이지 소개

- **`discography.html` — DISCOGRAPHY**: 역대 앨범(미니 8장 + 정규 1장)을 전체화면 영상 배경으로 구성. 스크롤로 앨범이 전환되며, 중앙에 로고·발매연도·앨범 차수·앨범명을 표기. 하단 중앙 모션 아이콘으로 소리를 켜고 끌 수 있고 그 상태가 시각적으로 표현됩니다.
- **`archive.html` — ARCHIVE**: 거리 포스터 형식의 전곡 트랙 리스트. 포스터를 좌우로 넘기며, 곡 제목을 누르면 사이트를 벗어나지 않고 해당 곡이 재생됩니다.
- **`behind.html` — Behind The Scene**: 문을 두드려(knock knock) 내부로 들어가는 인터랙션 후, 비하인드 영상을 갤러리로 배치하여 무대 밖 모습을 소개합니다.

## 에셋 교체 (`assets.html`)

로고·배경 영상·비하인드 영상·트랙 음원을 한 곳에서 교체하고 설정 파일(`assets/js/media.js`)을 생성하는 관리 페이지입니다.
실제 음원 파일이나 이미지가 있다면 여기에서 연결하여 광고 없이 재생되도록 바꿀 수 있습니다.
